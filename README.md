# 한 줌 암기

한식조리기능사 실기 33개 메뉴의 양념을 외우는 모바일 우선 카드 앱입니다.

## 사용

- 메뉴·양념 검색, 전체·미학습·다시 보기·암기 완료 필터
- 카드별 양념 가리기와 전체 보기
- 현재 검색·필터에서 랜덤 암기, 답 확인 후 다음 카드
- 브라우저 로컬 학습 기록 저장, 오프라인 캐시
- 메뉴별 박문각 유튜브 링크

학습 기록은 기기·브라우저별로 저장되며 다른 기기와 동기화되지 않습니다. 데이터는 기존 정리표를 그대로 사용합니다. 음성 직접 청취 검증 및 정량 레시피는 포함하지 않습니다.

## 로컬 미리보기

`node server.cjs`를 실행한 뒤 출력되는 주소를 여세요. 별도 설치나 빌드가 없습니다.

## GitHub Pages

저장소 루트에 index.html, styles.css, app.js, data.js, sw.js, manifest.webmanifest, icon.svg, .nojekyll을 올립니다.
저장소 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다.
사이트를 연 다음 휴대폰 브라우저에서 홈 화면에 추가할 수 있습니다. 오프라인 기능은 온라인에서 한 번 방문한 뒤 사용할 수 있습니다.

`build-data.cjs`는 상위 폴더의 원본 Markdown에서 data.js를 갱신하는 로컬 보조 스크립트입니다. 배포할 때 실행할 필요는 없습니다.
